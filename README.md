<img src="./hd-projects.svg" width="620" alt="projects"/>

**[LLM Cost Ledger](https://github.com/tksluangrath/llm-cost-carbon)** &nbsp;&middot;&nbsp; <samp>python, mcp</samp><br>
MCP server that answers what an LLM call actually cost, reconciling<br>
ccusage-captured usage logs from Claude Code, Codex, OpenCode, and Amp.<br>
Local-only: no proxy, no cloud infrastructure, no telemetry.

**[Podscope](https://github.com/tksluangrath/podscope)** &nbsp;&middot;&nbsp; <samp>python, pyspark, neo4j</samp><br>
Local NLP pipeline that transcribes YouTube videos, segments them by<br>
topic, summarizes each two ways, extracts entities, and graphs what<br>
recurs across a channel. No paid APIs: faster-whisper and a local Ollama<br>
model do the work a hosted API usually would.

**[Frequency-Based Speech Isolation for Keyword Spotting](https://github.com/tksluangrath/ds6050-audio-projects)** &nbsp;&middot;&nbsp; <samp>python, pytorch</samp><br>
CNN vs. Audio Spectrogram Transformer for keyword spotting under noisy<br>
conditions, tested across three preprocessing strategies and five SNR<br>
levels. The CNN won every configuration (93.42% clean, 81.94% at -5 dB<br>
with bandpass filtering).

**[Fraud Detection ML Pipeline](https://github.com/tksluangrath/fraud-detection-app)** &nbsp;&middot;&nbsp; <samp>python, azure</samp><br>
Trained on 6.3M+ PaySim transactions, 94% recall and 0.99 ROC-AUC on a<br>
severely imbalanced dataset (0.13% fraud). Shared train/serve pipeline on<br>
Azure ML and Container Apps, so the deployed model always matches what<br>
was validated in training.

**[AURA-ED](https://github.com/XinnieMai/AURA-ED)** &nbsp;&middot;&nbsp; <samp>python, llm</samp><br>
Clinical decision-support tool that synthesizes fragmented ED patient data<br>
into structured early risk profiles, built on the Stanford MC-MED dataset<br>
(118,385 adult ED visits).

**[Oregon Trail Fitness](https://github.com/RichyKim12/Gold-Rush-Fitness)** &nbsp;&middot;&nbsp; <samp>fastapi, healthkit</samp><br>
Built at HoosHack 2026. An Oregon Trail-themed iOS fitness tracker pulling<br>
real step data from Apple HealthKit. I built the FastAPI backend and the<br>
HealthKit integration.
