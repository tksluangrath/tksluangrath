Every graphic here is generated, not embedded from anyone else's server.<br>
The stat graphics and these section headings are drawn by [a scheduled<br>
action](.github/workflows/stats.yml) straight from the GitHub GraphQL API,<br>
once a day, committing only what changed.

They animate with SMIL inside the SVG, because GitHub strips scripts from<br>
READMEs — and since nothing loads from a third party, nothing here can<br>
rate-limit or go dark. The headings are SVGs for the same reason: GitHub<br>
also strips CSS, so an image is the only way to put this page's own<br>
typeface on them.

The typeface is [JetBrains Mono](scripts/fonts), subset to just the<br>
characters each graphic draws and inlined as base64. Language totals cover<br>
public repositories only.

after the example at [andriidrok1/andriidrok1](https://github.com/andriidrok1/andriidrok1).
